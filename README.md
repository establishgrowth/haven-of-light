# Haven of Light website

Static website for Haven of Light CIC (Hafan o Oleuni), North Wales.

## Pages
- `index.html` – home / landing page
- `global-justice.html` – issues, modern slavery stats, spot the signs
- `learn.html` – education, churches & community, speaker booking
- `events.html` – events and awareness days
- `donate.html` – donation page (hands off to Localgiving)

## Editing
Each page is plain HTML. Open it in any text editor, change the words, save, and upload.
Anything in [square brackets] is a placeholder to replace with real details.

## Hosting
Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
